# TAILORA

### Better days for better companions.

TAILORA is a premium pet lifestyle storefront for dogs and cats, built around thoughtful everyday essentials, calm editorial design, and a clear shopping experience.

## Features
- 16 individual product images stored locally
- One dedicated product photo per product card
- Product/category filtering
- Shopping bag demo
- Responsive desktop, tablet, and mobile layouts
- Editorial collections and brand story
- Dedicated customer support section
- GitHub Pages compatible static site

## Image standard
Every product card uses its own local square image. No product card reuses a collage or composite catalog image. Each image is cropped from an individual catalog tile and presented with `object-fit: cover` inside its own frame, keeping the product centered and isolated.
